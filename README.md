
# Cybersecurity Incident Portal

## Overview
Cybersecurity Incident Portal is a simple HTML-based project designed to demonstrate basic web development skills while focusing on cybersecurity concepts.

The portal allows users to:
- Report security incidents
- Review common cybersecurity threats
- Access security awareness tips
- Contact the security team

---

## Features
- Home Page
- Incident Reporting Form
- Incident Categories
- Security Tips
- Contact Page
- Multi-Page Navigation

---

## Technologies Used
- HTML5
